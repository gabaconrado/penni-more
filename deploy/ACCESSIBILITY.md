# Accessibility release checklist

Before a release, record the date, browser, assistive technology, viewport, flows tested, and all
findings. Verify the following manually:

- Complete primary desktop and phone flows using only the keyboard. Confirm logical focus order,
  visible focus, a working skip link, and no focus traps.
- With a screen reader, verify headings, landmarks, accessible names, validation messages, and
  status announcements.
- At 200% zoom and with forced colors, verify content remains usable without horizontal scrolling.
- Verify reduced-motion preferences are respected and meaning is never communicated by color alone.
